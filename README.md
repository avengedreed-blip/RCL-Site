# Reed Creative Labs Website

Official static website for Reed Creative Labs.

Built with:

- Next.js App Router
- TypeScript
- Tailwind CSS
- Static export

## Local Development

```bash
npm install
npm run dev
```

## Production Checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Deployment

Deploy on Vercel as a Next.js project. The production domain is:

```text
reedcreativelabs.com
```
